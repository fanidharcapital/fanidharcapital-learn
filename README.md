# Shree Fanidhar Capital — Learning Series

Educational platform and structured lesson series covering Indian equity markets, market infrastructure, settlement cycles, trading mechanics, and risk management, published by **Shree Fanidhar Capital**.

- **Live Site:** [learn.fanidharcapital.com](https://learn.fanidharcapital.com)
- **Main Website:** [fanidharcapital.com](https://fanidharcapital.com)
- **Built With:** Astro, TypeScript, Tailwind CSS, and AstroPaper v6

---

## Project Structure

- `src/content/posts/` — Markdown lesson files for the learning series
- `public/images/lessons/` — Diagrams and visual assets for lessons
- `src/components/Header.astro` — Two-line responsive header and navigation menu
- `src/utils/getSortedPosts.ts` — Lesson sorting utility ordering lessons sequentially by lesson number
